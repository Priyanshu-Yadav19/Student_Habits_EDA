# 📊 Student Habits & Performance — Exploratory Data Analysis

This project explores how lifestyle factors such as sleep, diet, and study habits impact student academic performance. It includes data cleaning, visualization, and statistical analysis using Python.

## 🔧 Tools Used
- Python
- pandas
- numpy
- matplotlib
- seaborn
- scipy

## 📈 Key Features
- Imputed missing values using median/mode strategies  
- Detected outliers using the IQR method  
- Visualized distributions with histograms, boxplots, and countplots  
- Generated correlation heatmaps and pairplots to uncover relationships between habits and performance  
- Saved cleaned dataset snapshot for future modeling or dashboard integration
